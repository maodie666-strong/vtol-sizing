# vtol-sizing

**垂直起降飞行器总体参数快速权衡工具**（概念设计阶段）

给定任务剖面（航程 / 悬停时间 / 爬升高度）与设计参数（桨盘载荷、翼载、电池比能量等），
求解满足任务的最小起飞重量，并给出重量构成、功率需求、能量分配与参数敏感性排序。

零第三方依赖，Python 3.9+ 直接运行。

---

## 快速开始

### 方式一：Web 交互界面（推荐演示用）

直接双击打开 `index.html`，或起一个本地服务：

```bash
python -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765/
```

拖动滑块实时看结果变化：21 个参数分 5 组，3 个预置方案（小型物流机 / 中型载货 eVTOL / 载人 eVTOL），
输出指标卡片、重量构成、能量分配、关键参数表、敏感性 tornado 图、桨半径扫描曲线，结果可导出 CSV。

界面**完全离线可用**——图表是手绘 SVG，不依赖任何 CDN，面试演示不怕断网。

### 方式二：Python 命令行

```bash
python demo.py
```

输出四个案例：中型 eVTOL 方案求解、小四旋翼验证、参数敏感性分析、桨盘载荷扫描。
扫描结果自动导出到 `output/`。

在代码里调用：

```python
from vtol_sizing import VTOLConfig, size

cfg = VTOLConfig(range_km=100.0, payload_mass=200.0, n_rotor=8, rotor_radius=0.90)
res = size(cfg)

print(res.mtow)               # 起飞重量 kg
print(res.hover_power / 1000) # 悬停电功率 kW
print(res.lift_to_drag)       # 巡航升阻比
```

## 跨语言数值一致性验证

Web 界面用的是 `vtol-web/model.js`，它是 Python 内核的移植版。为了保证两边**永远算出同一个数**，
建立了一套跨语言回归测试：

```bash
python vtol-web/dump_reference.py   # 1) 从 Python 导出全精度基准 → reference.json
node vtol-web/verify.js             # 2) 用 JS 复算并逐项比对
```

当前结果：**63 项全部通过，相对误差 0.0e+0（容差 1e-9）**。

覆盖范围：案例 1 的全部重量构成 / 四个功率点 / 气动系数 / 能量分配、
案例 2 的悬停航时、22 项参数敏感性排序与幅度、15 点桨半径扫描。

这套测试的价值在于：改动物理模型时，只要两边同步改，回归测试会立刻指出不一致的项。

## 物理模型

### 1. 旋翼（悬停 / 轴流爬升）— `rotor.py`

概念设计阶段的标准做法：动量理论 + 品质因数（FM）修正。

```
v_h     = sqrt(T / (2 ρ A))          悬停诱导速度
P_ideal = T · v_h
P_shaft = P_ideal / FM
```

FM 把剖面功率、桨尖损失、入流非均匀性一次性归并。小型螺旋桨 0.60–0.70，
优化过的大直径旋翼 0.75–0.82。

爬升状态用轴流解：`v_i = (-V_c + sqrt(V_c² + 4 v_h²)) / 2`，爬升率为 0 时退化回悬停。
电功率 = 轴功率 / (电机效率 × 传动效率)。

### 2. 机翼（巡航）— `wing.py`

巡航段由机翼承载全机重量。升力线斜率采用 Helmbold 形式
`a = 2π·AR / (AR + 2)`，阻力极曲线 `CD = CD0 + CL² / (π·AR·e)`。
巡航功率 = 阻力 × 速度 / 螺旋桨效率 / 电机效率。

### 3. 重量 — `weight.py`

| 分系统 | 估算依据 |
|---|---|
| 结构 | MTOW × 结构重量系数（0.25–0.35） |
| 动力系统 | 峰值轴功率 ÷ 功率密度（3000–8000 W/kg） |
| 旋翼系统 | 最大推力 ÷ 推力密度（200–350 N/kg） |
| 航电 / 载荷 | 固定值 |
| 电池 | **由任务能量需求反推** |

### 4. 能量与闭合 — `energy.py` + `sizing.py`

电池重量由任务能量反推，而任务能量又依赖 MTOW —— 这构成隐式方程：

```
MTOW = W_struct(MTOW) + W_prop + W_rotor + W_avionics + W_payload + W_battery(MTOW)
```

`sizing.py` 用带松弛因子的不动点迭代求解，典型 15–25 次迭代收敛到 1e-7 相对残差。
发散时返回明确警告（说明任务需求超出了能量可行性边界）。

`demo.py` 案例 2 用公开机型量级做一阶校验：

| 项目 | 数值 |
|---|---|
| 构型 | 4 旋翼，桨径 27.9 cm（11 inch） |
| 起飞重量 | 2.00 kg（电池 0.50 kg，220 Wh/kg，DoD 85%） |
| 品质因数 | 0.62 |
| **模型预测悬停航时** | **26.4 min** |
| 同级机型实测 | 25 – 30 min |

量级一致，说明一阶估算可用于方案比较与趋势判断。

## 已知局限

这是**概念设计阶段**工具，用于方案比较与趋势分析，不能替代详细设计：

1. **不含气动干扰**：多旋翼之间的下洗干扰、机身遮蔽效应未建模。
2. **不含过渡状态**：倾转 / 转换飞行段的气动与功率特性未覆盖。
3. **准定常假设**：机动飞行、阵风响应未考虑。
4. **结构重量用经验系数**：没有基于实际结构布局做有限元。
5. **电池一阶模型**：无放电曲线、无热管理、无低温衰减。
6. **巡航用机翼承载假设**：适配 lift + cruise 与倾转构型，多旋翼构型需另算。
